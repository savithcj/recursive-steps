Loads a RUN.json from the ontology-grounded executor and renders the tree, the composition violations, and what the run contributed to the ontology. This page never decomposes anything — the local system owns all execution. ← the step decomposer

Goal
Produced by python3 run.py --offline. Statuses: executed ran as a leaf, composed passed its composition checks, reused deduped to an earlier node, failed did neither. Composition checks validate the shape of a run — a consumed artifact with no producer, a type mismatch, two owners for one name. They do not check whether a value is right.
